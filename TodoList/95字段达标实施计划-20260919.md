## 2. 未满足目标的功能（按根因分组）

### RC1 — LLM 请求被网关 60s 超时（占 67/68 失败）

失败字段：part_06(20)、part_11(15)、part_10(11)、part_03(8)、part_01(5)、part_04(4)、part_07(3)、part_08(2)。

**已确认证据（非推测）：**

- 各失败节点耗时约 180s ≈ `timeout=60s × 3 次尝试`（OpenAI SDK 默认 `max_retries=2`）。
- `mlc_agent/integration.py:100` 构造客户端时 `timeout=60.0`。
- 用本次运行的真实 part_06 payload（180KB）复现：非流式请求在 **60.3s** 收到服务器 **504 Gateway Time-out**（ALB 网关超时）。
- 同一 payload 改用 `stream=True`：**成功返回，总耗时 130.5s，首 token 8.3s**。
- 结论：网关对“非流式完整响应”有 60s 上限；流式在 60s 前就开始回传 token，因此不会被网关切断。单纯调大客户端 timeout 无效，必须改为流式。

### RC2 — Part 11 聚合的 dict/模型类型不匹配（代码 bug）

即使某个 Part 11 子组抽取成功，`board_officer_material_change`、`regulatory_status` 仍失败：

```
'dict' object has no attribute 'source_url'
```

**已确认证据：**

- `evidence_text_documents()` 返回 `list[dict[str, Any]]`（`production_adapters.py:430`）。
- `collect_part11_groups()` 形参声明为 `list[EvidenceDocument]`（`audit_changes.py:602`），内部 `_document_for()` 直接访问 `item.source_url`（`audit_changes.py:216-227`）。
- `part11_node` 在“存在 group_errors”分支直接把 dict 列表传给 `collect_part11_groups`（`integration.py:698-729`），绕过了 Pydantic 强转。
- 现有测试 `tests/test_part11.py:63-66` 直接传 `EvidenceDocument` 模型，因此没有覆盖生产路径，测试全绿但线上必错。

### RC3 — Part 11 restatement 组级失败隔离不彻底

`Part11RestatementExtraction` 在 Pydantic 校验阶段抛出：

```
No restatement status requires an explicitly negative quotation
```

导致整个 restatements 子组失败（`financial_restatement_status`、`financial_restatement_details`）。

**已确认证据：**

- `audit_changes.py:120-127` 的 `validate_status` 在模型校验时强制 `has_explicit_negative_statement()`。
- 该校验发生在 `extract_pydantic` 的 `model_validate_json` 内，异常使整个组丢失，而不是只标记这两个字段。

### RC4 — 验收口径与项目目标不一致（需业务确认）

- 当前设计导致“有明确失败原因的合法部分成功”被判定为 `finalize failed`，与目标冲突。

```python
# mlc_agent/llm.py（新增常量与函数）
LLM_TIMEOUT_ENV = "LLM_TIMEOUT_SECONDS"
LLM_MAX_RETRIES_ENV = "LLM_MAX_RETRIES"
DEFAULT_LLM_TIMEOUT_SECONDS = 300.0
DEFAULT_LLM_MAX_RETRIES = 1


def get_llm_timeout() -> float:
    _load_env()
    raw = os.getenv(LLM_TIMEOUT_ENV, "").strip()
    return float(raw) if raw else DEFAULT_LLM_TIMEOUT_SECONDS


def get_llm_max_retries() -> int:
    _load_env()
    raw = os.getenv(LLM_MAX_RETRIES_ENV, "").strip()
    return int(raw) if raw else DEFAULT_LLM_MAX_RETRIES


def chat_completion_text(llm_client, *, model, messages, temperature=0.0) -> str:
    """Return completion text, streaming so gateways do not cut long responses at 60s."""
    result = llm_client.chat.completions.create(
        model=model, messages=messages, temperature=temperature, stream=True
    )
    # Test doubles and some compatible servers return a complete response object.
    if hasattr(result, "choices"):
        content = result.choices[0].message.content
        return content or ""
    parts: list[str] = []
    for event in result:
        choices = getattr(event, "choices", None)
        if not choices:
            continue
        piece = getattr(choices[0].delta, "content", None)
        if piece:
            parts.append(piece)
    return "".join(parts)
```
